SHACL validator

Our RDF data validation too uses the Shapes Constraint Language, SHACL, validate RDF against either rules. The rules can be supplied by the user or selected from a number of preloaded validators we have collected from our work.

The tool is built on top of the pySHACL open source validation tool and is available online at:

  • https://tools.kurrawong.ai/validate.

The preloaded validators it contains are sourced from a list of validators in our Semantic Background, a reference set of semantic resources we maintain.
