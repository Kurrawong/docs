# PrezUI 

Until v4 of Prez (current as of September 2026), the _User Interface_ (UI) of Prez has been a separate project: https://gihub.com/RDFLib/prez-ui.

As of v5 Prez (due late September 2026) Prez & PrezUI will be combined into just 'Prez' with the UI being an optional 
module.

Documentation for Prez UI is currently at the link above but will be placed into https://prez.dev when v5 is launched.
